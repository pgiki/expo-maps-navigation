# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Preferred options:

1. **GitHub Security Advisories** on this repository (Private vulnerability reporting), once the repo is public
2. Email the maintainers at **dev@fikachu.com**

Include:

- Description of the issue and impact
- Steps to reproduce or a proof of concept
- Affected versions / platforms (iOS / Android / Expo SDK)

We aim to acknowledge reports within **7 days** and to provide a remediation plan or fix timeline after triage.

## Non-security bugs

Use [GitHub Issues](https://github.com/fikachu/expo-maps-navigation/issues) with the bug template.
